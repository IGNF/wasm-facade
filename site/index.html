wasm-facade reads inert attributes on a Rust crate compiled with wasm-bindgen and writes what a JavaScript user calls: a TypeScript facade, React hooks, a reference, and any binding a plugin adds (Python, React Native, a web component). Change the Rust, run wasm-facade generate, and every binding follows.

orval, for Rust and wasm

orval reads an OpenAPI document and writes a typed client and TanStack Query hooks: the contract is written once and the client never drifts. wasm-facade does the same for a library compiled to WebAssembly.

wasm-bindgen already writes declarations for what it exports. That surface is the engine's: numeric enums, positional arguments, Function, free() to remember. wasm-facade writes the layer a user calls on top of it: unions of strings, options objects with their defaults, on(event, listener), promises, converters from the user's own types.

In a repository

1. Declare the API in Rust

The attribute is behind a cfg that is never set: nothing is compiled, no proc-macro, no dependency, no build time.

/// A blur's options
#[cfg_attr(wasm_facade, api(options))]
pub struct BlurOptions {
    /// Its radius, pixels
    #[cfg_attr(wasm_facade, api(default = "2"))]
    pub radius: f64,
    /// How it reads past the edges
    #[cfg_attr(wasm_facade, api(default = "'clamp'"))]
    pub edge: Edge,
}

/// A box blur, applied to RGBA pixels in place
#[cfg_attr(wasm_facade, api(class, options = "BlurOptions"))]
#[wasm_bindgen]
impl Blur { … }

2. Configure the targets

# wasm-facade.toml, at the repository's root
wasm = "../pkg/filters.js"         # the wasm-bindgen module, as the facade imports it
converters = "src/converters.ts"   # the project's converters (ImageData → Uint8Array…)

[targets.typescript]               # src/api.ts
[targets.react]                    # src/hooks.ts
[targets.reference]                # docs/api.md
[targets.python]
plugin = "scripts/api/python.ts"   # a target of the project's own

3. Generate, and check in CI

$ wasm-facade generate   # after changing the Rust
$ wasm-facade check      # in the lint: fails on any drift

The result, for a small image-filters crate: new Blur({ radius: 4, edge: 'wrap' }), blur.apply(imageData, w, h), blur.on('progress', …), useBlur(options) in React. The demo runs it and shows each generated file beside the Rust it comes from.

Plugins

A target is a module whose default export takes the API and returns files. The built-in ones are typescript, react and reference; a project adds its own, built from the same generic patterns (unions, options, classes, events, converters). isard, its first user, adds a Python widget, React Native and a web component this way.
